# Data Statement

IssueSense ML currently uses two datasets:

## Synthetic/Curated Training Dataset

- Generated by `issuesense.generate_dataset`.
- Current size: 540 records.
- Balanced across six labels.
- Generated from engineering issue templates that include API failures, requirements ambiguity, environment failures, data quality issues, performance problems, and integration mismatches.
- Used for train/validation/test splits.

Because this dataset is template-generated, synthetic-test metrics can be very high. These metrics prove that the pipeline works, but they should not be presented as production-level model performance.

## Manual Challenge Dataset

- Stored at `data/challenge/issues_challenge.csv`.
- Current size: 36 records.
- Manually written, not used for training.
- Contains noisier and less template-like reports.
- Used to evaluate generalization and identify errors.

For interviews and CV claims, use the manual challenge metrics as the more honest performance signal.

## Safe Wording

Use:

> Created a synthetic/curated engineering issue dataset and a separate manually written challenge set to evaluate model generalization.

Avoid:

> Trained on real enterprise Bosch data.

Avoid:

> Achieved production-ready accuracy.
